A tiny Node 22 (stdlib-only) program that writes one joke about crypto and trading life to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

## The line

> I bought the dip, then the dip bought a dip, and now I own a diversified portfolio of regret, all down 87% and technically 'long-term holds'.
